C Issue Tracker

A command line issue tracking program written in C, made with GCC, make and git. 

Features:
    - Creates issues
    - View issues
    - Updates issues
    - Close issues
    - Delete issues
    - Search issues
    - Save & Exit issues
    - Input validation

Concets:
    This program consists of structs, pointers, arrays, strings, dynamic memory allocation, file I/O, modularity and function. 

How to Run?

Compile to project: make

Run the program: ./Issure-Tracker
